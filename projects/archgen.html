ArchGen — Agentic Architecture Diagram Generator

The Goal & Problem

Building complex AI agents and systems often requires a "Big Picture" first. Jumping straight into code without a clear architecture leads to messy logic and integration headaches. ArchGen bridges the gap between idea and implementation, providing a visual and documented "source of truth" before you write a single line of application code.


How It Works

ArchGen uses a Sequential Agentic Workflow powered by Google ADK:

  • The Architect: Analyzes your requirement and designs a structured system graph.
  • The XML Coder: Converts that graph into Draw.io XML for professional editing.
  • The Blueprint Writer: Generates a comprehensive Markdown technical proposal.


Key Features

  • Guided Prompting: Start quickly with templates and suggestion chips.
  • Smart Canvas: Powered by React Flow with snap-to-grid and auto-layout (Dagre).
  • Bring Your Own Key (BYOK): Securely use your own Gemini API quota via session-based key input.
  • Multi-Format Export: Export to PNG, XML (Draw.io), and Styled PDF blueprints.
  • Version History: Automatically tracks every generation so you never lose a design.


Tech Stack

Built with FastAPI, React Flow, Google Gemini, and Google ADK.
