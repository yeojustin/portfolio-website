L2 Depth & Quoting Simulator

The Goal

I built this project to watch how the Bid-Ask spread moves in real-time and to understand order book mechanics without risking actual money. It serves as a local testing ground where I can try out different quoting ideas and see how they would perform against live market data before ever placing a real trade.

How It Works

The simulator bridges real market data with a local execution engine:

—
Live Sync: It maintains a local Binance Spot L2 order book by pulling an initial REST snapshot and applying WebSocket depth diffs on top of it.
—
Simulation: It runs a local simulation on that live book. It computes order book imbalance (OBI), generates virtual quotes, tracks theoretical inventory, and processes fake fills whenever the quotes cross the real touch price.
—
Terminal UI: Everything is visualized in the terminal using Rich, giving a clear, tick-by-tick view of the order book and the simulated trades.



Under the Hood

The project is written entirely in Python. To handle the high volume of websocket messages without lagging behind, it relies heavily on Python's asyncio. I also structured the codebase to decouple the book synchronization loop from the actual simulation logic, making it much easier to swap out or tweak trading strategies later on.
