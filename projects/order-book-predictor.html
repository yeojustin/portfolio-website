Order Book Price Movement Predictor

The Goal

The primary goal of this project is to predict short-horizon Bitcoin (BTC) price direction by analyzing real-time Binance Level-2 order book data. High-frequency algorithmic trading relies heavily on understanding market microstructure—knowing exactly where liquidity rests and how aggressively it is being consumed. By engineering specialized features like order book imbalance (obi), spread, and depth skew, this pipeline anticipates micro-price movements before they occur.

System Design & Architecture

Rather than a simple static script, this application is designed as a end-to-end proof of concept for continuous learning pipeline. It features a multi-symbol raw data collector that streams websocket data and feeds it into a modular transformation engine. The core of the system operates in two main runtime modes: a live inference mode that scores every single tick using the latest machine learning artifac that was trained prior with XGBoost and PyTorch, and a batch mode for historical validation (which is currently still under work in progress).

Drift-Triggered Auto-Training

One of the standout design choices in this architecture is the "drift-triggered auto-train" mechanism where you can flag it to use it upon starting the app.

Cryptocurrency markets are highly volatile, and statistical edges decay rapidly when the market regime changes. To combat this, the pipeline continuously monitors for feature-distribution drift during live operation. If the incoming live data statistically deviates past a set threshold compared to the baseline training data, the system autonomously triggers a model retrain, ensuring the predictive engine remains razor-sharp without manual intervention.

Key Results and Performance

The baseline XGBoost model achieved 53.2% accuracy in predicting the next tick's direction (higher than the 50% random guess), with AUC of 0.530. It also demonstrated strong performance on classifying large price moves, hitting 72.8% accuracy on >0.01% directional change prediction and 68.6% on >0.02% moves. These metrics provide a solid foundation for the ongoing enhancement work. Future work would be to increase the model's sophistication (e.g. deep learning models) and expand the feature engineering set.
